# RaidTrace plugin releases

Release downloads of the RaidTrace Dalamud plugin.

To install RaidTrace, add this custom plugin repository in Dalamud
(Settings → Experimental → Custom Plugin Repositories):

    https://releases.raidtrace.com/dalamud/repo.json

Each release here is tagged `dalamud-vX.Y.Z` and holds the plugin's zip and
its SHA-256 checksum. Dalamud downloads them for you; there's no need to
download anything from this page.

More at https://raidtrace.com.
